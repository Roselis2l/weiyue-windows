# 1.1.19 候选更新说明

本候选调整阅读交互、表情和图片兼容。实际 Windows EXE 验收结果与附件哈希以随候选提供的独立验证报告为准；构建成功不等于 EXE 验收通过。

| 改动 | 使用方式与边界 |
| --- | --- |
| 路径表情 | 新增官方票券原图对应的 `[/ee84a5.png]`，支持半角及全角括号；共 408 个映射、407 份官方原图。未知代码和加载失败保留原文，不猜测别名。 |
| 空白区域拖动 | 在消息周边空白区域按住左键拖动可滚动列表；正文可正常选择复制，链接和控件仍可点击。松开、离窗或失焦时停止。 |
| 引用信息 | 旧记录支持一次受限信息补全，已有真实微博引用及其已取得的配图仍可打开。官方详情和目标列表没有原消息 ID 或原图地址的引用显示“网页版未提供原图信息”；本轮核查的这类引用仍不能打开，不推测配图。 |
| 系统通知 | 依据明确协议类型识别的系统通知收为一行，可展开查看全文；普通群成员消息不因群名、昵称或相似文字被误折叠。 |
| 图片兼容 | 修复部分官方图片声明格式与实际内容不一致导致的加载失败；聊天图片按真实支持格式显示与另存为，保留原图字节。HTML、SVG、未知或缺少 MIME 的响应仍拒绝，头像及 AI 图片校验不放宽。 |
| 重点样式 | 昵称保持加粗和主题色，浅色背景仅覆盖消息内容区；头像与昵称区域透明。取消重点立即恢复，已读、选择及收藏状态保留各自标记。 |

保留视频和实况照片预览自动播放、受限 HEVC 本机兼容预览、HEIF、PDF、原文件保存、分钟筛选、收藏摘要和本地回收区。表情来源与覆盖边界见 [微博表情说明](WEIBO-EMOTICONS.md)，操作步骤见 [使用说明](使用说明.md)。

日常仍使用一个固定安装目录。升级前完全退出并完整备份，替换程序文件时保留原 `data/`；候选包不自动覆盖日常安装。本地回收仍为可恢复隐藏，首次实际回收后的账号格式 2 规则不变；不能使用 1.1.16 及更早版本直接打开格式 2。

开发验证使用隔离数据或明确授权的本机只读资料，不回收真实消息、不调用收费 AI 或写入真实 Notion，不将真实图片、群聊或诊断日志放入源码与便携包。
