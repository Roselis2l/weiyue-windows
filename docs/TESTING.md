# 测试与 Windows 复核

本文件记录 1.1.25 的本地验收与复核方法。全量单测 1091/1091、源码窗口 13/13、最终包内 EXE 13/13 已通过。公开包只整理 README、文档和合成示例图；应用、测试、脚本及运行库与验收版逐字节一致。附件哈希以同批次 SHA256SUMS.txt 为准，不据本地测试声称 GitHub CI 通过。

## 核心测试

```powershell
.\scripts\test.ps1
```

全量单测 **1091/1091** 通过，零失败、零跳过。源码窗口 **13/13** 与最终 EXE **13/13** 通过，删除动作使用独立合成账号。真实 Windows 文件读锁造成原子提交失败时，原文件字节不变；30,000 条处理中正常关窗会等待完整提交后退出。最终 EXE 100,000 条清理与 UI 收束约 1021 ms，真实处理阶段可见，40 ms 界面心跳最大间隔 43.8 ms；这些单次响应性检查不是所有数据规模的保证。

本轮复核默认回收、直接永久删除、回收区所选批次永久删除、精确筛选与保护规则、确认取消/过期/重复提交、失败原子性、真实阶段进度、重启与防同步补回。覆盖清理后当前群刷新、首尾与中间消息移除、空结果、保留筛选、群/账号切换、读取位与未读集合保护。格式 1/2 的读取不迁移；首次非空永久删除升 3，旧版必须拒绝读，非法或含正文的删除标记拒绝。

实际窗口与最终 EXE 使用隔离合成账号验证删除动作，不在原始真实数据或真实回收区执行。性能测试可使用已授权的本机只读数据分析与私有隔离副本，禁止将正文、成员、群名、账号、媒体地址、截图或凭据放入公开产物。记录同一数据规模、过滤条件、冷/暖路径及采样方法，比较磁盘读写/解析/校验、过滤排序、分页、DOM 和交互延迟；不得只凭单测宣称流畅。优化后的消息顺序、稳定 ID 全集和过滤结果须与基线相同。指标和实际采用的优化以同批报告为准。

已在同一本机数据隔离副本上比较 1.1.24 与本版：未变文件复用经过校验的内存快照，避免每次查询重复同步读盘、解析和全库校验；文件变更会使缓存失效。内部只读快照与调用者可修改的副本分开，写入继续原子保存。数据规模为 39,020 条、约 17 MB 的本机私有隔离副本，最大群 18,516 条；暖查询与状态快照各取 7 次中位数，实际阅读位置写入取 3 次中位数。首次内部读取仍约 302 ms。代表性同条件结果如下；原始私有副本和诊断记录不公开分发。

| 本机操作 | 1.1.24 | 1.1.25 |
| --- | ---: | ---: |
| 缓存已建立后的 160 条分页查询 | 约 287 毫秒 | 约 6.6 毫秒 |
| 读取界面状态快照 | 约 897 毫秒 | 约 8.8 毫秒 |
| 实际改变阅读锚点并保存 | 约 699 毫秒 | 约 530 毫秒 |

这些是该次本机操作测量，不是网络耗时、渲染帧率或所有规模下的承诺。阅读锚点实际改变后仍需序列化并写入整份账号文件，因此仍有明显成本；本轮未改为数据库或增量日志。首次冷读取、搜索排序、长时间累积 DOM 和媒体解码仍需按各自路径评估，不把暖查询改善推广为所有操作已经即时。

双向分页、自动更新、外观、媒体、收藏、摘要及账号隔离继续回归，不扩大真实网络调用。单账号锁、外部文件变化、同步与清理争用、worker 异常、临时文件/原子替换失败及关闭等待要有针对性验证，不能用吞掉错误维持表面成功。

以下保留 1.1.22 的调度复核依据，本轮不改其实现：5 秒完成后调度、慢请求单飞、后台群至少 60 秒头页间隔、前台与缺口公平轮转、8 页/8 秒软预算、含身份确认与分页的自动整轮 20 秒总中止、单请求 12 秒超时、每页至少 1 秒间距、未闭合缺口的独立 60 秒重试与前台持续刷新不延后重试、断网与服务错误退避、429 Retry-After 与 401/403 停止、暂停恢复和跨账号隔离。离线模型按稳定 ID 全集比较新增缺口消息，重复页不算新增量。

跨批公平性须覆盖一批仅成功一个慢页时仍保存下一工作类别；计入后台头页的所有非当前群头页成功请求累计最多 4 页后插入当前群头页，且不重置后台与缺口轮次。还须覆盖同群多个未闭合缺口轮转、普通缺口持续推进不推迟未闭合缺口独立 60 秒资格。20 秒整轮在途取消与 5 秒空闲成功后等待分别验收，不据此宣称当前群或全部群的端到端新消息可见时间。

同步服务使用相同 180 秒离线页面服务模型，比较旧 60 秒/60 页/40 秒与新 5 秒/8 页/8 秒策略。按稳定 ID 全集差集统计新增缺口消息，重复头页不计入：

| 每页服务耗时 | 旧策略新增缺口消息 | 新策略新增缺口消息 | 模型内变化 |
| --- | ---: | ---: | ---: |
| 100 毫秒 | 1340 | 1680 | +25.4% |
| 3500 毫秒 | 300 | 320 | +6.7% |
| 8100 毫秒 | 140 | 140 | 持平 |

三组模型中的补扫量没有下降。独立调度复核已通过 3.5 秒与 8.1 秒慢成功页、20 个后台群轮转、同群多个未闭合缺口轮转及失败不消费轮转槽位检查。这些结果仅属于离线服务模型，不包含真实网络压力测试，不代表实际速度、普遍提升比例、官方请求频率承诺或端到端体验保证。以上调度模型属于旧版保留记录，不冒充本轮重新压测结果。

同一 39,020 条合成 fixture，最终 EXE 对比 1.1.24：启动显示 160 条 4.370→0.917 秒（单次）；160 条查询 IPC 157→27 ms（5 次中位数）；下一页 1.096→0.478 秒、搜索/清除 1.430→0.819 秒（各 3 次中位数，后者含防抖和恢复）。两版均为 160 条、3042 个消息区 DOM 后代，滚动 RAF 中位约 8.3 ms，未见超过 50 ms 的样本；滚动本身与旧版相当。零外部请求、零页面错误，窗口正常退出。1.1.24 及更早测试数量只作历史记录，不相加。

删除动作测试只使用合成数据或明确隔离副本。须核验收藏、摘要来源、导出关联、未读、阅读及同步锚点保护；缺失来源时保守保留；同步、补扫或导入不恢复已回收/永久删除消息；最小标记仍参与同步边界。失败不伪称成功，原文件和阅读状态不半提交。首次实际回收升为 2、首次非空永久删除升为 3，仅预览不升级，恢复不降版本。永久删除不表示磁盘安全擦除，也不删除历史备份。

## Windows 界面与隔离集成

使用独立测试 profile、合成消息和模拟服务，不登录真实账号、不删除真实聊天、不调用付费 AI 或写入真实 Notion。脚本的实际参数、环境变量和运行范围以各文件注释为准。相关入口包括：

- `scripts/ui-smoke.cjs`：版本与启动。
- `scripts/cleanup-125-integration.cjs`：本轮清理确认、回收/永久删除、实际进度、当前群刷新、切群与阅读保护；源码窗口和最终 EXE 分开记录。
- `scripts/appearance-124-integration.cjs`：普通正文独立颜色、旧配置兼容、预览/取消/保存/恢复默认/重启、身份切换及阅读状态；实际执行结果单独记录。
- `scripts/auto-page-123-integration.cjs`：1.1.23 双向分页、四键、滚轮、拖动、边界与焦点排除及阅读状态；源码与未改写最终 EXE 分别记录。
- `scripts/refresh-122-integration.cjs`：既有合成账号的实际 5 秒墙钟调度、当前群优先、后台轮转、冷却及阅读状态；按实际执行版本记录结果。
- `scripts/appearance-121-integration.cjs`：历史六项颜色、默认色、自动与显式正文色、预览/保存/取消/恢复默认及旧配置保留。

- `scripts/bubble-media-121-integration.cjs`：既有媒体气泡、配色与几何边界，使用独立安全导航；结果以实际执行为准。

## 验证边界

真实登录、平台风控、服务器可见历史、真实 AI 模型兼容性、Notion 权限与写入不由模拟测试证明。自动化中文组合测试不等同于 Windows 原生输入法人工验收。已获授权的真实媒体只读验证应单独记录结果，原始文件不进入源码或便携包。

测试产生的 artifacts、profile、备份和诊断截图不随软件分发。本版不会自动升级日常安装或执行历史目录清理。
