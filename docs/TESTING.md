## 核心测试

使用 Node.js 22 或更高版本运行：

```powershell
.\scripts\test.ps1
```

全部核心测试完成后，再验收实际 Windows 窗口和打包 EXE。不要仅运行新增模块测试，也不要将不存在的 CI 或未执行的真实服务联调写为通过。

本轮重点：

- XLSX、Markdown、CSV 的格式与编码识别、大小/解压/行列/文本边界、损坏文件、缓存公式不执行、外链和 HTML 不执行。安全预览、明确截断提示、原件保存和取消、重复点击、关闭/切换时停止旧任务。
- 实况照片与分享语音的确证源结构、权限和来源白名单；源字段不足时显示真实限制。自动播放只由用户打开预览触发，关闭和切换须停止旧媒体。继续回归 HEIF、GIF、PDF、视频兼容转换与原件下载。
- 四个精确路径表情的官方资产格式、hash、内联显示及复制原代码；未知代码和 URL 保持原文，不将表情作为用户图片传给 AI。
- Cool Grey、Viridian、Pink、Violet 四种主题的保存重启、反复切换、取消、独立恢复默认、旧配置与账号隔离。七项聊天自定义颜色不得被主题覆盖；昵称、正文、链接、系统通知和媒体控件各守自身规则。检查窄窗口、焦点、阅读锚点/高水位及未读不变。

## 窗口与包内 EXE

所有开发和破坏性测试使用完全合成账号或隔离副本；不对真实消息和回收区执行回收、恢复或永久删除。真实消息只在本机进行用户授权的只读诊断与来源核对，不进入公开截图、测试源码或交付包；不调用真实 AI/Notion。

实际 EXE 复核必须确认 `isPackaged`、版本、可执行路径、应用源码路径、隔离数据路径和应用文件 hash。安全选项继续保持 sandbox、contextIsolation、webSecurity；renderer 不得取得 Node 权限。分别记录模拟媒体测试与真实源验收，不能将 mock 成功当成真实账号成功。

完整回归保留分页、IME 搜索、选择、收藏、重点切换、摘要、清理、设置和账号隔离。使用键盘 PageUp/PageDown/方向键，以及滚轮和空白拖动到上下边界；程序恢复、图片高度变化和自动同步不应自行连续载入。加载不回退高水位，不把未看到的消息读完，普通正文仍可选字。

自动更新继续维持当前群正常完成后等待 5 秒、其他群约 60 秒轮转、共享单飞/分页限流、失败退避、429 Retry-After 和 401/403 停止。不得扩大真实网络压测；调度单测应能证明修改主题或附件不会改变同步语义。

清理回归使用合成样本核对默认可恢复回收、永久删除确认/取消/重复提交、保护规则、真实进度、原子失败和当前群刷新。旧数据预览不迁移格式；非空永久删除升格式 3 的既有边界保留。大群性能改进沿用 1.1.25 的缓存和有界 DOM，不将上轮测量值当作本轮重新实测结果。

## 打包与安装核验

在干净候选中使用已验证的 Electron 44.9.0 归档打包：

```powershell
.\scripts\package.ps1 -ElectronVersion 44.9.0 -OutputDirectory dist-1.1.26
```

禁止覆盖已有构建。冻结源码后对源码 ZIP、便携目录、便携 ZIP 全条目校验，确认各文件来自冻结源码或已核验 Electron 归档；核对第三方许可证、对应源码和校验文件。白名单不得包含账号数据、浏览器状态、凭据、真实媒体、私有诊断、测试副本或备份。

日常升级前正常关闭应用并等待写入结束，完整新备份与原目录逐文件比对 SHA256；再确认备份期间原目录未变化。只更新程序文件，原 `data/` 在替换前后必须逐字节相同。受控启动后核对两个账号的稳定消息 ID 全集、收藏/备注/标签、摘要、导出关联、重点成员、所有自定义设置与阅读关键状态。新同步消息和允许的视口偏移分别报告，不得以总数增长掩盖消息缺失。

最后恢复用户日常窗口。出现未知写入/启动/上传结果时先检查现有状态，禁止盲重试；不删除回滚备份或历史程序目录。发布副本只整理 README 和公开文档，应用、测试、构建脚本及许可证与已验收候选逐字节一致。
