# 测试与 Windows 验收

1.1.27 GitHub 版的冻结源码全量测试 **1217/1217 通过**，无失败、取消或跳过。本地测试结果不代表 GitHub CI；发布时应另查发布提交的检查状态。真实账号的重新登录不在开发测试中执行，AI 与 Notion 使用模拟接口，不代表真实服务联调通过。

## 核心测试

使用 Node.js 22 或更高版本，在源码目录运行：

```powershell
.\scripts\test.ps1
```

本轮重点覆盖：

- 登录成功后仅解除当前账号的会话失效暂停，按原设置恢复自动更新；手动关闭保持关闭，原群选择保留，新发现的群默认不选。重复登录、旧请求尚未结束、切换账号、重启不产生重复定时器或并发请求。权限拒绝、风控及限流冷却仍保留。
- 左右栏独立收起与展开、偏好持久化、窄窗口、键盘可操作性；阅读锚点、未读、选择及收藏草稿保持。
- PDF 预览的宽度布局与渲染生命周期：自动适应宽度才重画，翻页、缩放、调整窗口、滚轮、重复打开和后台自动更新不会循环重绘；关闭取消待执行绘制。
- GitHub 版只显示已收到的明确撤回状态，不显示撤回原文及附件；相关摘要和可能包含摘录的收藏备注也隐藏。账号隔离、延迟响应、旧数据兼容、永久删除墓碑及主动删除不被撤销。

回归还覆盖精确分钟筛选、成员搜索及中文输入法、双向键盘和鼠标分页、收藏与摘要、主题和独立消息颜色、HEIF/GIF/PDF/视频/实况/语音、文档与压缩文件安全下载、消息回收及永久删除保护。媒体和文档不执行文件内脚本；未知引用或表情保持可解释的文字回退。

## 实际窗口与 EXE

源码通过后还应运行打包后的实际 Windows EXE，核实版本、GitHub 版标识及应用文件与源码的对应关系。登录验收使用隔离合成账号、真实 IPC 和实际五秒调度；网络由内存模拟传输替代，不借用其他账号会话。检查登录恢复、重复登录、手动关闭、权限暂停、跨账号及重启六组行为，分别记录执行结果。

使用合成数据验证双栏布局、窄窗口及阅读状态；PDF 和媒体测试分别记录模拟样例和经授权本机原件的覆盖范围，不将真实内容、截图或私密诊断材料放入公开源码或附件。保持 sandbox、contextIsolation 和 webSecurity，渲染进程不获取 Node 权限。

自动更新仍为当前群一轮完成后等待五秒，其他已选群约六十秒轮转；实际包含请求、补扫和退避时间。这是本地调度策略，不是官方频率保证。请求保留单飞、队列公平性、失败退避、429 Retry-After 冷却与认证/权限停止，不使用真实接口压力测试。

所有回收、恢复、永久删除测试均使用隔离数据，不对用户真实原始记录执行删除。只在首次成功持久保存新的撤回状态时升级为账号格式 4；仅打开和投影不写入格式迁移。旧版降级须恢复升级前完整备份，不能忽略未知格式继续读取。
