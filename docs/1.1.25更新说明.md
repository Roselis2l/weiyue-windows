# 微阅 Windows 1.1.25

“设置与连接 → 管理本地消息与回收区”保留默认可恢复回收，并增加直接永久删除。按群、北京时间起止分钟和保留规则预览，核对范围、数量及不可恢复提示后再确认。回收区也可对所选批次永久删除，未选批次保持。

中间栏显示实际清理阶段和可取得的处理计数。只有保存成功才显示完成；仍在受影响群时重新读取消息与分页计数，切换群或账号不会跳回原位置。处理期间防止重复提交，保留筛选、阅读高水位与未读规则。

收藏、摘要来源、导出关联、未读、阅读与同步锚点继续保护；无法确认来源范围时保守保留。永久删除移除当前账号活动数据中的消息正文、成员与媒体信息，只保留群 ID、消息 ID、发送时间的最小标记，防止自动同步、补扫和导入立即补回。

永久删除不能由回收区恢复，也不是磁盘安全擦除。它不删除服务器记录、历史备份、浏览器缓存或已导出文件，旧副本可能仍在这些位置。首次非空永久删除将账号格式升为 3；1.1.24 及更早版本不能读取。预览或取消不升级格式，回收/恢复也不会把格式 3 降回旧版。

大群读取复用经过文件指纹验证的快照，减少反复同步读盘、解析和校验整库。同规模合成数据的最终 EXE 下一页中位耗时从约 1.10 秒降至 0.48 秒；实际读写条件与限制见 [测试说明](TESTING.md)，不把单测通过当作流畅度证明。既有 5 秒当前群优先调度、双向翻页、外观与媒体功能保留。

便携版请固定日常安装目录。更新前正常退出并完整备份，只更新程序文件并保留原 `data/`。首次非空永久删除后若需降级，须使用永久删除前的完整备份并另存当前数据。测试未在真实账号或其回收区永久删除内容，也未调用真实 AI/Notion。

本轮全量单测 1091/1091、源码窗口 13/13、最终包内 EXE 13/13 通过；公开包的应用代码、脚本及运行库与验收版逐字节一致，仅整理公开文档和合成图。详见[中文说明](使用说明.md)与[复核说明](TESTING.md)。
