# 微阅 Windows 1.1.16

离线积压消息改为单并发、按群轮转的连续分页。自动每轮有 40 秒及 60 页预算，手动补扫有 90 秒及 120 页预算，页请求之间至少等待 1 秒；每页仍使用已核实的请求参数 20 条。实际返回数量和完成速度由微博响应决定，不承诺固定每分钟条数。

补旧消息期间也检查实时消息。各段未衔接游标独立保存，重启可继续；接口提前结束或重复返回一页不会被当作历史已经补全。身份、权限及风控问题暂停；限流遵守服务端等待，手动与自动同步共用冷却约束。

当前群的状态显示补入条数、回溯位置和暂停原因。“补齐离线消息”继续中段续扫；“更早历史”只向本地最早记录之前读取。同步不推进已读位置，不跳转阅读视口。

便携版的每个运行目录有独立 `data/`。移动数据前应退出应用、保留回滚备份，并按账号、群和完整消息 ID 核对。离线合并工具保留目标设置及阅读位置；冲突双方保留，收藏和摘要引用不改写，不能用整个旧 data 覆盖新目录，也不能默认复活仅在历史备份存在的已删除收藏或摘要。

开发和回归使用合成消息与模拟接口，不调用收费 AI 或真实 Notion 写入。本说明不代表微博服务器全部历史已完整返回。
