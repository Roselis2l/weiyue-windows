# 1.1.46 更新说明

- 新增 DOCX 原文件下载与只读正文预览，保留下载字节。预览不还原版式、图片、页眉页脚或批注，不执行宏、嵌入对象和外部链接。文件上限 20 MiB，正文最多显示 20 万字符。
- 阅读日期筛选在离开输入框或按回车后提交，分段输入时保留上次结果；未填完整的时间不会误当无边界筛选。
- 同步公共与本地版本的附件窗口来源校验，后台内容刷新只关闭已失效的附件窗口。
- 图片窗口支持同一消息、分享帖或引用内的前后切换，左右键切换、Shift+左右平移；GIF链接返回静态JPEG时明确提示。

## 已知边界

- 原图链接不保证实际返回动画。保存以文件真实格式为准，不能从静态 JPEG 恢复完整 GIF。
- 分享帖仅呈现平台已返回、当前账号可访问的图片；缺失原帖或撤回前未缓存的媒体无法恢复。
- 未发现足够证据确定此前一次窗口进程消失的根因，本版不宣称已修复该问题。
- 补齐状态描述历史覆盖，摘要依据选定时段、成员和已保存消息生成；两者不是同一范围保证。

本版不改变登录权限、撤回策略、已读状态或账号数据。两种发行包独立生成，公开包不含私有策略及个人数据。
