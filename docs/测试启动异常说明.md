# Windows 测试启动异常排查

记录实际退出状态和脱敏错误分类，区分源码错误、运行时损坏、测试宿主限制和交互桌面不可用。单一错误字符串不能证明某条 ACL、网络策略或平台权限是原因。

`scripts/windows-runtime-check.cjs` 提供只读环境检查，不等价于完整文件权限 AccessCheck。使用完整源码、校验过的 Electron 运行时和获准的普通 Windows 测试环境。

不要禁用沙箱、修改 ACL、证书校验、系统安全设置或应用访问控制来制造通过结果。被拒绝或执行结果不确定时保留现状，先核实是否已执行，再处理具体原因；不要通过反复启动或换路径冒充修复。

复验方法见 [TESTING.md](TESTING.md)。私人事件日志、进程号、用户路径和历史机器记录不随公开包分发。
