# 本地归档范围与完整性

资料按账号保存消息文字、成员/时间、已取得的媒体描述、阅读位置、未读状态、收藏、摘要及导出日志。收藏与摘要的引用可回到本地原文，不是公开可访问的微博链接。

图片及附件通过账号会话按需取得，显示缓存主要在内存中。保存过 URL 不等于已下载原文件；要独立留存，应在查看器另存为。HEIC 在本地转 PNG 显示，保存原图保留原 HEIC 字节。PDF 及支持编码的 MP4/WebM 可在附件查看器查看和保存。限制见 [使用说明](使用说明.md)。

同步只访问用户选中且有权访问的群。消息 ID 保持字符串，历史分页以当前最小 ID 减一推进；增量同步与历史游标分开保存。达到本轮页数限制不表示全部历史已经取得，平台未返回、已删除、隐藏、权限变化及失效附件仍可能缺失。

同步、布局和媒体加载不自动推进阅读边界。各群恢复消息锚点；真实阅读及明确跳转按阅读规则处理。搜索只查询已存本地消息，不补齐未同步内容；清除最后一个筛选后恢复普通阅读位置。

时段摘要保留覆盖缺口提示与引用。本地综述是摘录；AI 需要配置、预览和主动确认，不因显示媒体自动发送。Notion 也须预览确认。

备份前退出应用并完整备份该安装的 data 目录。不同安装的数据不自动合并；导出日志可能含原文与编辑草稿，应按聊天资料保护。发行包不包含账号资料、凭据、真实媒体、运行缓存、内部诊断或安装备份。

1.1.16 的自动补扫每轮最多 40 秒/60 页，手动最多 90 秒/120 页，页间至少 1 秒；同时检查新消息并持久化未衔接区间。达到本轮预算并不表示完整历史已取回。固定一个日常安装目录，升级时退出、备份并保留原 data；新解压目录不会自动带入旧资料。详见 [1.1.16 更新说明](1.1.16更新说明.md)。
