# 安全与限制（1.1.22）

## 数据保存

应用按账号隔离本地聊天记录、回收区、收藏、摘要、阅读状态和服务设置。演示与导入使用独立工作区。

Portable 默认将数据写入 `WeiYue.exe` 同目录的 `data/`；源码运行使用 `.local-data/`。聊天正文、备注、摘要和导出日志使用本地文件保存，**没有对全部业务数据做加密**。Markdown / JSON 导出和另存为的图片、PDF、视频也是未加密文件。请把数据放在受控的 Windows 用户目录，并自行保护备份。

微博 Cookie、AI Key 和 Notion Token 通过 Electron `safeStorage` 使用 Windows 凭据保护后保存，不写入普通设置。凭据保护不可用时拒绝保存密钥；换 Windows 用户或设备后，旧凭据可能无法解密。应用设置不回显已保存 Key。

账号隔离防止应用内交叉使用数据和会话，不替代操作系统访问控制，也不防止已经能够读取当前用户文件或控制当前进程的其他程序。

本地回收使用账号内的持久化回收标记与批次，保留原始记录和同步边界。始终保护收藏、摘要引用、导出关联、未读与阅读定位；历史来源不明确时保守保留并提示。确认令牌短期有效、单次使用并绑定账号与群，确认前重新核对快照。保存失败不会先从界面移除消息。回收副本与普通消息同样未整体加密，仍需要保护数据目录。

第一次实际回收后，该账号使用格式 2，恢复全部消息也不会降回格式 1。1.1.16 及更早版本会拒绝读取格式 2，防止旧版忽略回收标记而错误显示数据。首次打开软件或只做预览不升级格式。降级回滚必须使用启用回收前的完整备份，同时另存当前完整数据以保护后续新增内容。

触底自动翻页只追加展示当前筛选下的本地后续消息：向下滚轮触底一次，或空白拖动触底并松开后一次追加 160 条。它不发起微博网络读取，不等于“加载到最新”或离线补扫，也不会因消息刚被追加就读完未看内容。

## 自动同步边界

自动更新正常完成后等待 5 秒再检查，优先当前正在阅读的已选群。其他已选群从上次最新页完成起至少等待 60 秒，再公平轮转；群数较多、网络慢或正在补扫时可能更久，不是全部群每 5 秒请求。后台新消息仍按各群原规则计入未读，不打开该群也能更新。

自动批次最多 8 页、8 秒软预算，页请求之间至少 1 秒，共用单飞和限流保护；正在执行的单个请求可能使实际批次超出软预算。单个请求超时仍为 12 秒，自动整轮（含身份确认和分页）另有 20 秒总中止计时。前台最新页与历史缺口交错，成功批次仅等 5 秒继续，保留每页落盘游标，不把重复页当作新增量或缺口完成。身份检查、请求耗时及补扫均计入实际等待，因此 5 秒只是空闲成功周期下限。该数值是本地工程选择，不是微博公布或保证的接口频率。

后台头页和缺口工作的轮次跨批次保留，包括一批只有一个慢成功页的情况。所有非当前阅读群头页的成功页（含后台头页）累计最多 4 页后插入当前群头页，同时保留被让出的后台与缺口轮次。20 秒限定整轮在途取消，不是当前群或全部群的端到端新消息可见时间保证。

平台提前结束而未能衔接的缺口不会被误标为完成；首次可探测一次，之后的探测独立冷却至少 60 秒。正常前台头页不会重置这项缺口冷却，以免每 5 秒反复请求或一直无法重试。同群多个未闭合缺口轮转，普通缺口的持续推进不会推迟其独立重试资格。正在推进的普通缺口仍可按短批次继续。

网络或服务错误从 60 秒开始退避，最长 15 分钟；429 至少冷却 60 秒并遵守更长的 Retry-After，暂停后恢复也不会缩短冷却。401、403、身份变化、风控及其他明确拒绝会停止，等待用户在官方页面确认后主动恢复。 自动与手动读取共用账号冷却，不通过切换账号或按钮重复请求缩短服务等待。自动更新不推进阅读高水位、不把新消息一概标已读，也不把本地触底翻页变成网络拉取。

本轮以合成数据验证调度与异常，不对真实接口进行压力测试；没有官方频率下限证据，不把 5 秒写作官方承诺。

## 外观设置

六项颜色按当前账号保存，显式颜色只接受 #RGB 或 #RRGGBB，重点正文另支持自动模式，不将颜色输入作为任意 CSS 执行。颜色选择和局部合成预览不需要网络请求，也不修改聊天、阅读位置、收藏、摘要或凭据；只有保存才提交当前账号的外观设置。恢复默认只修改当前草稿。显式重点正文色和昵称色低对比时提示，不擅自改色；正文自动模式才保证相应对比度。已有五项自定义配色保留，缺失的重点正文项按自动模式处理。

## 网络行为

| 动作 | 对外发送或读取的范围 |
| --- | --- |
| 官方登录 | 在独立窗口访问微博官方页面，由用户完成登录和验证。应用不采集密码，也不借用其他应用凭据。 |
| 群聊同步 | 使用当前登录会话读取已选、有访问权限的群聊。正常完成后 5 秒再检查当前阅读群，其他群最新页至少间隔 60 秒轮转；可暂停，实际等待包含请求与补扫耗时。 |
| 显示头像 | 登录确认时随正常群列表保存群头像；手动同步读取一次群列表，仅刷新已选目标群的头像，自动更新不额外请求群列表。成员头像来自已取得的消息，不遍历无关联系人。头像经过按账号隔离的本地代理按需加载，失败保留默认占位。 |
| 显示微博表情 | 本次已核验的官方公开目录原图随应用本地加载并缓存，不发送文字、不联网取图，也不作为 AI 图片输入。目录外代码保留原文；当前范围为旧公开目录、正常官方选择器中已核实的默认名称及逐项核实的路径，不等于全部专属或动态目录。 |
| 本地消息回收 | 用户先预览账号、群、北京时间分钟范围、保留规则与数量，再确认移入可恢复回收区。不会删除服务端内容，不释放磁盘空间；自动同步不恢复已回收消息，恢复需主动操作。 |
| 下载压缩文件 | 对明确的官方附件元数据，验证允许来源、上限 200 MiB、MIME 与 ZIP/RAR/7z 签名后，通过系统对话框保存原字节，不解压、不运行。 |
| 显示媒体 | 通过受限代理按需读取允许来源的图片、PDF、视频或分享信息；媒体处理在本机完成，不在启动时从 CDN 取解码器。 |
| 保存媒体 | 用户通过系统“另存为”选择目标路径，保存已校验的原始文件字节；HEIC 本地转换只用于显示，保存仍保留原 HEIC。取消不写入，覆盖同名文件需正常确认。 |
| 生成本地摘录 | 不联网，仅处理当前群、所选时段的本地记录。 |
| 删除本地摘要 | 用户确认后按当前账号、群和摘要 ID 删除对应本地记录；取消或保存失败时保留。没有网络请求，不删除聊天、收藏、阅读位置、导出日志或已存在的 Notion 页面。 |
| 准备 AI 内容 | 仅处理所选群与时段的消息。必要时通过当前已授权微博会话补充普通分享正文和图片；此阶段不向 AI 服务发送聊天或图片。 |
| AI 总结 | 用户核对范围并确认后，将成员名称、时间、消息文本、可读取的分享正文和被列为可发送的图片数据发到选定服务。长记录分段请求，图片可能增加 token 用量与费用。 |
| Notion 目标读取 | 使用用户提供的 Token 读取已授权目标页面。 |
| Notion 导出 | 用户编辑预览并确认后，将标题、正文和所选引用写入指定页面下的新子页面。 |
| 打开外链 | 仅允许符合校验的 HTTP / HTTPS 网页，点击后交给系统默认浏览器；不在聊天窗口执行远程网页。HTTP 不提供 HTTPS 的传输保护。 |

没有后台定时 AI 调用或 Notion 发送。AI 请求失败不会自动重试、切换模型或服务，也不会隐式调用 OCR。未知模型能力、内容获取失败、正文截断、不支持的图片格式和超出预算都会在发送前明确提示；未发送内容不应视为已由模型读取。已发送请求的服务端处理与计费不因本地取消而保证撤销。Notion 对无法确认是否已成功的写入停止重发，保留本地状态供核对。

## 运行边界

主界面与独立图片查看器开启沙箱和上下文隔离，关闭 Node 集成；仅通过受限 preload 接口执行已定义操作。图片查看器无原生标题栏不代表取消安全隔离。官方登录页与本地应用界面分离，导航及新窗口受限制。聊天、备注和模型文本作为内容显示，不作为页面脚本执行。

聊天图片入口允许在受支持的 PNG、JPEG、GIF、WebP 声明与实际文件签名之间纠正格式不一致；必须仍通过允许来源、响应格式、体积与字节校验。缺失 MIME、HTML、SVG 或未知格式不因此被接受，头像与 AI 图片路径保留原有严格校验。纠正只改变显示格式及保存扩展名，不改写原图字节。

系统通知依据官方协议字段分类，不以昵称或群名猜测。图片引用只有在取得明确的原消息或原图信息后才能打开；一次旧记录补全不能恢复官方接口没有提供的目标。缺失信息时显示“网页版未提供原图信息”，不按邻近消息或相似内容匹配原图。

HEIC 使用本机固定版本 libheif-js，在独立沙箱和可终止 worker 中解码。该任务只接收已读取的有界字节，不接收微博会话、任意路径或网络地址；网络、文件来源、输入大小、输出 PNG 大小、像素及时间受限。原图最多 20 MiB，显示 PNG 最多 64 MiB。主界面的沙箱、上下文隔离和网络限制不会为了兼容图片而关闭。

PDF 附件最多 50 MiB，使用固定本地 PDF.js 在画布中预览，不执行文档活动脚本。视频原文件最多 200 MiB，仅接受受支持来源与格式的 MP4 / WebM。视频或实况照片预览在用户打开后自动播放，提供暂停、音量和进度控制；列表不自动播放。打开预览后，原生解码失败的短 HEVC 自动进行一次本机兼容转换：输入最多 20 MiB、时长最多 30 秒，并受尺寸、像素、运行时限及输出大小限制。准备时明确显示本机处理状态，关闭窗口可取消；失败只提供主动重试，不自动循环。FFmpeg 在本机隔离 Worker 处理，不借用会话或访问外部转码服务。兼容转换成功后自动开始预览，原文件字节不变；无法预览时仍可保存已通过校验的原文件。媒体入口不能由聊天文本注入任意文件路径或任意外部下载地址。切换账号会使旧查看器及读取失效；已保存的独立文件不随切换删除。

PDF、视频和本地转换的 HEIC 不自动进入 AI / Notion 发送范围。所有媒体显示都不等于授权第三方分析这些媒体。HEIC 和 FFmpeg 对应源码、重建材料和第三方许可随包提供；PDF.js 与字体许可也一并保留。FFmpeg 核心为 GPL-2.0-or-later 组件，具体材料与重建限制见 [FFmpeg 说明](FFMPEG-THIRD-PARTY.md)。

AI 提供方地址必须使用 HTTPS；仅本机回环地址允许 HTTP。AI 请求不跟随重定向。图片只能从允许的来源经过受限代理读取，并校验实际格式和体积；不能通过图片地址读取任意本机文件或任意外部地址。聊天、分享微博和图片里的文字都属于待总结资料，不拥有应用工具权限，AI 输出中的无效引用会提示需要核实。

头像与聊天附件使用独立路径。头像目前只允许 HTTPS 的 `sinaimg.cn` 及其子域，校验实际图片格式；单图最多 1 MiB、同一时间最多 4 个读取任务，每个任务最多 8 秒。内存缓存总量最多 16 MiB、最多 512 项，成功结果约 15 分钟后失效，失败结果短暂缓存约 1 分钟；冷却结束后允许正常界面刷新重新尝试同一地址，不绕过平台拒绝或身份限制。切换账号或退出会中止相关任务并清理缓存，旧账号代理地址不能用于新账号。头像地址和字节不加入 AI 内容准备、摘要引用或图片附件列表。

异常显示会隐藏已知凭据及常见敏感字段。脱敏不代表任意用户粘贴内容都能被自动识别；对外提交问题时仍应检查文本。

## 备份、分享与反馈

完全退出应用后再备份整个数据目录。导出单份摘要或收藏、手动另存为图片，不等同于完整数据备份。媒体链接可能失效，本程序不保证完整离线归档。

提交 Issue 或分享截图时，只提供版本、操作步骤、预期结果和脱敏后的错误类别。不要上传自己的数据目录、登录状态、Cookie、Token、API Key、真实群聊原文或未经检查的导出文件。优先使用演示数据复现。

真实微博返回字段、媒体链接和权限状态可能变化；离线兼容测试不能证明指定真实图片已修复，也不能由网页失败推断 Android 客户端的具体请求方式。本项目不会绕过账号权限、登录验证、平台风控或群访问限制。未经代码签名的 portable 包可能触发系统来源提示；应核对下载来源与 SHA256，并遵循设备安全策略。
