# 安全与限制（1.1.16）

## 数据保存

应用按账号隔离本地聊天记录、收藏、摘要、阅读状态和服务设置。演示与导入使用独立工作区。

Portable 默认将数据写入 `WeiYue.exe` 同目录的 `data/`；源码运行使用 `.local-data/`。聊天正文、备注、摘要和导出日志使用本地文件保存，**没有对全部业务数据做加密**。Markdown / JSON 导出和另存为的图片、PDF、视频也是未加密文件。请把数据放在受控的 Windows 用户目录，并自行保护备份。

微博 Cookie、AI Key 和 Notion Token 通过 Electron `safeStorage` 使用 Windows 凭据保护后保存，不写入普通设置。凭据保护不可用时拒绝保存密钥；换 Windows 用户或设备后，旧凭据可能无法解密。应用设置不回显已保存 Key。

账号隔离防止应用内交叉使用数据和会话，不替代操作系统访问控制，也不防止已经能够读取当前用户文件或控制当前进程的其他程序。

## 网络行为

| 动作 | 对外发送或读取的范围 |
| --- | --- |
| 官方登录 | 在独立窗口访问微博官方页面，由用户完成登录和验证。应用不采集密码，也不借用其他应用凭据。 |
| 群聊同步 | 使用当前登录会话读取已选、有访问权限的群聊。默认每 60 秒更新，可暂停。 |
| 显示头像 | 登录确认时随正常群列表保存群头像；手动同步读取一次群列表，仅刷新已选目标群的头像，自动更新不额外请求群列表。成员头像来自已取得的消息，不遍历无关联系人。头像经过按账号隔离的本地代理按需加载，失败保留默认占位。 |
| 显示微博表情 | 本次已核验的官方公开目录原图随应用本地加载并缓存，不发送文字、不联网取图，也不作为 AI 图片输入。目录外代码保留原文，公开目录不等于登录后专属或动态表情目录。 |
| 显示媒体 | 通过受限代理按需读取允许来源的图片、PDF、视频或分享信息；媒体处理在本机完成，不在启动时从 CDN 取解码器。 |
| 保存媒体 | 用户通过系统“另存为”选择目标路径，保存已校验的原始文件字节；HEIC 本地转换只用于显示，保存仍保留原 HEIC。取消不写入，覆盖同名文件需正常确认。 |
| 生成本地摘录 | 不联网，仅处理当前群、所选时段的本地记录。 |
| 删除本地摘要 | 用户确认后按当前账号、群和摘要 ID 删除对应本地记录；取消或保存失败时保留。没有网络请求，不删除聊天、收藏、阅读位置、导出日志或已存在的 Notion 页面。 |
| 准备 AI 内容 | 仅处理所选群与时段的消息。必要时通过当前已授权微博会话补充普通分享正文和图片；此阶段不向 AI 服务发送聊天或图片。 |
| AI 总结 | 用户核对范围并确认后，将成员名称、时间、消息文本、可读取的分享正文和被列为可发送的图片数据发到选定服务。长记录分段请求，图片可能增加 token 用量与费用。 |
| Notion 目标读取 | 使用用户提供的 Token 读取已授权目标页面。 |
| Notion 导出 | 用户编辑预览并确认后，将标题、正文和所选引用写入指定页面下的新子页面。 |
| 打开外链 | 仅允许符合校验的 HTTP / HTTPS 网页，点击后交给系统默认浏览器；不在聊天窗口执行远程网页。HTTP 不提供 HTTPS 的传输保护。 |

没有后台定时 AI 调用或 Notion 发送。AI 请求失败不会自动重试、切换模型或服务，也不会隐式调用 OCR。未知模型能力、内容获取失败、正文截断、不支持的图片格式和超出预算都会在发送前明确提示；未发送内容不应视为已由模型读取。已发送请求的服务端处理与计费不因本地取消而保证撤销。Notion 对无法确认是否已成功的写入停止重发，保留本地状态供核对。

## 运行边界

主界面与独立图片查看器开启沙箱和上下文隔离，关闭 Node 集成；仅通过受限 preload 接口执行已定义操作。图片查看器无原生标题栏不代表取消安全隔离。官方登录页与本地应用界面分离，导航及新窗口受限制。聊天、备注和模型文本作为内容显示，不作为页面脚本执行。

HEIC 使用本机固定版本 libheif-js，在独立沙箱和可终止 worker 中解码。该任务只接收已读取的有界字节，不接收微博会话、任意路径或网络地址；网络、文件来源、输入大小、输出 PNG 大小、像素及时间受限。原图最多 20 MiB，显示 PNG 最多 64 MiB。主界面的沙箱、上下文隔离和网络限制不会为了兼容图片而关闭。

PDF 附件最多 50 MiB，使用固定本地 PDF.js 在画布中预览，不执行文档活动脚本。视频最多 200 MiB，仅限受支持 MP4 / WebM，实际编码兼容性由 Electron 决定；播放器不自动有声播放。媒体入口不能由聊天文本注入任意文件路径或任意外部下载地址。切换账号会使旧查看器及读取失效；已保存的独立文件不随切换删除。

PDF、视频和本地转换的 HEIC 不自动进入 AI / Notion 发送范围。所有媒体显示都不等于授权第三方分析这些媒体。HEIC 对应源码、重建材料和第三方许可随包提供；PDF.js 与字体许可也一并保留。

AI 提供方地址必须使用 HTTPS；仅本机回环地址允许 HTTP。AI 请求不跟随重定向。图片只能从允许的来源经过受限代理读取，并校验实际格式和体积；不能通过图片地址读取任意本机文件或任意外部地址。聊天、分享微博和图片里的文字都属于待总结资料，不拥有应用工具权限，AI 输出中的无效引用会提示需要核实。

头像与聊天附件使用独立路径。头像目前只允许 HTTPS 的 `sinaimg.cn` 及其子域，校验实际图片格式；单图最多 1 MiB、同一时间最多 4 个读取任务，每个任务最多 8 秒。内存缓存总量最多 16 MiB、最多 512 项，成功结果约 15 分钟后失效，失败结果短暂缓存约 1 分钟；冷却结束后允许正常界面刷新重新尝试同一地址，不绕过平台拒绝或身份限制。切换账号或退出会中止相关任务并清理缓存，旧账号代理地址不能用于新账号。头像地址和字节不加入 AI 内容准备、摘要引用或图片附件列表。

异常显示会隐藏已知凭据及常见敏感字段。脱敏不代表任意用户粘贴内容都能被自动识别；对外提交问题时仍应检查文本。

## 备份、分享与反馈

完全退出应用后再备份整个数据目录。导出单份摘要或收藏、手动另存为图片，不等同于完整数据备份。媒体链接可能失效，本程序不保证完整离线归档。

提交 Issue 或分享截图时，只提供版本、操作步骤、预期结果和脱敏后的错误类别。不要上传自己的数据目录、登录状态、Cookie、Token、API Key、真实群聊原文或未经检查的导出文件。优先使用演示数据复现。

真实微博返回字段、媒体链接和权限状态可能变化；离线兼容测试不能证明指定真实图片已修复，也不能由网页失败推断 Android 客户端的具体请求方式。本项目不会绕过账号权限、登录验证、平台风控或群访问限制。未经代码签名的 portable 包可能触发系统来源提示；应核对下载来源与 SHA256，并遵循设备安全策略。
