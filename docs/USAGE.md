# 使用说明

## 启动与工作区

将 portable ZIP 完整解压到当前 Windows 用户可写的目录，双击 `WeiYue.exe`。程序首次运行会创建虚构演示工作区；“打开演示”可以再次进入它。演示、导入和微博账号是分开的工作区，可在左侧账号选择器切换。

正式 portable 运行时，数据保存在 `WeiYue.exe` 同目录的 `data/`。源码运行时默认保存在源码目录的 `.local-data/`。界面提供当前数据位置；升级或迁移前，请先完全退出程序，再备份整个数据目录。跨 Windows 用户或设备复制后，受保护凭据可能无法解密，需要重新登录或配置。

不要将自己的 `data/`、导出文件或备份作为软件发布附件。详细边界见 [安全与隐私](SECURITY.md)。

## 登录微博与同步

1. 点击“官方登录”并打开官方登录页。
2. 在独立窗口的 `https://api.weibo.com/chat` 页面自行完成登录和必要验证。
3. 返回应用，点击“我已登录，读取群聊”，等待身份确认和群列表读取完成。
4. 在“选择我的群聊”中勾选需要保存在本机的群，保存选择。
5. 使用“同步最近”获取最近记录，用“更早记录”继续读取历史。

已登录账号的已选群聊默认每 60 秒更新，可通过“暂停自动更新”停用，再按需恢复。取消选择群聊不会删除已保存记录。

同步受账号权限、官方接口和历史可见范围限制。遇到验证或会话过期，请在官方页面处理；读取失败可保留会话重试，不要反复退出重登。没有继续翻到的历史、平台未返回的内容和已删除消息不会凭空补齐。

应用不发送群消息。设置中的“退出微博网页登录”移除当前账号的登录会话，保留已经保存的聊天、收藏和摘要。

## 阅读与搜索

消息按时间正序展示，可翻页读取更早或更多内容。程序记住各群普通阅读位置，返回群聊时恢复；新消息到达后显示未读提示，“加载到最新”用于主动跳到末尾。

搜索框只搜索当前群已保存在本机的消息。可同时选择成员，在“更多筛选”中设置日期范围或只看重点成员。日期筛选的结束日期包含当日。消息旁的“设为重点”可标记成员。

中文输入时正常完成组词，组合结束后会延迟查询；普通 Enter 可立即查询。筛选视图不覆盖普通阅读位置，清除筛选会恢复原位置。若要反馈输入法问题，请提供 Windows 版本、输入法名称和不含真实聊天的复现步骤。

群聊图片可以点击查看原图；图片读取失败时可重试或在官方页面查看。图片文件不在本机形成完整离线归档，分享微博也可能只包含已取得的部分信息。

## 收藏与导出

点击单条消息的“收藏”，或勾选多条消息，再在工具区添加备注和逗号分隔的标签，选择“保存到价值收藏”。

“价值收藏”中可以搜索正文、备注及标签，修改备注标签，或移除收藏。移除收藏不会删除原聊天记录。“回到原文”定位本地消息；原文不在本地时需补充同步或导入。

Markdown / JSON 导出包含当前搜索条件匹配的收藏、备注及原文。它们是普通未加密文件，保存或分享前请检查内容。收藏 JSON 是收藏导出格式，不是下文的群聊导入格式。

## 指定时段回顾

1. 选择群聊，在“按时段回顾”中填写本机本地时间。
2. 时间边界为“开始包含，结束不包含”。可使用“今天”“昨天”“近 7 天”，或点击“此刻”把结束时间设为当前秒。
3. 点击“检查时段与内容”，查看消息数、分段数和覆盖提示。“查看待处理内容”展示前 20 条预览，不代表只处理这 20 条。
4. 选择“生成本地摘录”，或在配置 AI 后选择“使用 AI 总结…”。

本地摘录只统计和摘取原话，不推断观点或待办，不调用 AI。长记录按段处理，摘要会保留可回查引用。覆盖提示只能反映程序知道的同步与导入范围，不能保证平台端没有缺失内容。

生成结果自动保存在当前工作区的“时段摘要”中，可回查引用、导出 Markdown，或继续导出到 Notion。

## 配置与调用 AI

在设置中打开模型配置，选择服务商或自定义服务，填写兼容 Chat Completions 的服务地址、自己的 API Key 和实际 API 模型 ID。预设地址是填写辅助，服务权限、模型可用性和计费由对应提供方决定。

AI 和 Notion 设置分别保存。已保存 Key 不回显；更换服务商或服务地址时需要按界面重新确认对应凭据。保存设置本身不会发出 AI 请求。

发起总结时，先核对时段和待发送内容，再确认实际服务地址、模型、消息数和分段数。请求发送成员名称、时间和消息文本，可能产生费用。失败后不会自动重试或切换模型；如需重试，先检查错误，再重新确认发送。

所有 AI 结论都应通过引用核对。聊天内出现的指令属于被总结的资料，不应作为应用操作指令。

## 导出到 Notion

在 Notion 中创建或使用自己的 integration，并由你向需要写入的目标页面授予访问权。将对应 Token 填入应用的 Notion 连接设置。保存 Token 不会创建页面。

从摘要或收藏选择“导出到 Notion”；收藏支持单条或多选，一次最多 100 条收藏。读取已授权页面后选择目标，打开预览，编辑标题和正文。“引用原文与本地定位”默认勾选，可根据分享范围取消。

核对目标、标题、正文和引用后确认发送。应用在目标下创建子页面；引用中的群 ID、消息 ID 和时间用于在本地回查，不应理解为所有收件人都可打开的群聊永久链接。

完全相同的导出会复用本地记录；修改后的稿件作为新的导出版本。部分失败时，程序可能恢复原稿并续传已确认页面的剩余内容。若提示写入结果不确定，请先在 Notion 核对页面并保留本地导出日志，程序会阻止自动重发以避免重复。

## 导入自己的 JSON

点击“导入记录”选择 UTF-8 JSON 文件。每次导入创建独立工作区，不合并进当前微博账号。单次文件上限 30 MB，结构如下，示例均为虚构内容：

```json
{
  "groups": [
    { "id": "example-group", "name": "示例读书群" }
  ],
  "messages": [
    {
      "id": "9007199254740993",
      "groupId": "example-group",
      "senderId": "example-member",
      "senderName": "示例成员",
      "text": "这是一条用于演示导入的消息。",
      "time": 1767225600000
    }
  ]
}
```

`time` 是非负整数的 Unix 毫秒时间戳。`groupId` 应对应 `groups` 中的群；所有 ID 建议始终写成字符串，尤其不能把超出 JavaScript 安全整数范围的长数字写成 JSON 数值。只导入你有权使用的记录，文件中不需要 Cookie、密码或 API Key。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 无法启动或提示目录不可写 | 换到当前用户可写目录，保留原 `data/` 备份，不要直接覆盖。 |
| 登录完成但群聊未读取 | 检查官方窗口是否仍要求验证，再返回应用重试读取。 |
| 某时段无内容或提示缺口 | 先同步更早记录或导入相应记录，确认本地起止时间。 |
| 凭据无法解密 | 使用原 Windows 用户；迁移环境后重新登录和配置。凭据重置会替换旧凭据，但保留聊天、收藏和摘要。 |
| AI 请求失败 | 核对服务地址、API 模型 ID、权限及服务端限制，确认后再试。 |
| Notion 找不到页面 | 检查该 integration 是否已被授予目标页面访问权。 |
| Notion 写入结果不确定 | 先人工核对目标页面，保留本地导出日志，不连续重复发送。 |
