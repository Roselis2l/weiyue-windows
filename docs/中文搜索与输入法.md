# 当前群中文搜索与输入法

关键词只查询当前账号、当前群已同步或导入本机的消息，可叠加成员和时间筛选。不向微博、AI 或 Notion 发送关键词，也不检索尚未同步的内容。

先完成组词并确认汉字。组合输入期间不提交中间拼音；组合结束后延迟查询，普通 Enter 可提交已确认文字，候选确认键不同时搜索。后台刷新排队保留输入框和草稿，切换账号、群或页面时取消旧查询。

筛选不覆盖普通阅读锚点或已读边界。清除最后一个筛选后恢复原锚点和偏移，不删除原文、收藏或摘要。

输入中断时可记录应用版本、输入法、是否处于候选状态、是否切群及确认后实际保留的文字。无需提供完整群聊或任何密钥，不要删除 data 排查。

`scripts/message-search-ime-integration.cjs` 驱动 Chromium/CDP composition 管线并包含明确标识的模拟兼容事件，不能代替真实 Windows 输入法候选窗口的人工验收。准备与当前状态见 [TESTING.md](TESTING.md) 和 [1.1.16 更新说明](1.1.16更新说明.md)。
