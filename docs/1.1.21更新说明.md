# 1.1.21 更新说明

本版提供更紧凑的气泡、六项独立颜色设置和触底自动翻页。实际 Windows EXE 验收范围见 [测试说明](TESTING.md)，附件哈希见同批次 SHA256SUMS.txt；软件不会自动升级日常安装。

| 改动 | 使用方式与边界 |
| --- | --- |
| 紧凑气泡 | 减少正文周围冗余留白，保留文字字号与媒体可用尺寸；框外拖滚与框内正文选择、链接和控件操作互不抢占。 |
| 系统通知 | 系统通知使用透明背景的小字紧凑显示，不使用消息框、边框、阴影或尾角；长通知仍可展开，文字根据深浅聊天背景保持清晰。普通成员消息仍保留气泡，不因群名或昵称相似而误分类。 |
| 触底翻页 | 向下滚轮的每次连续手势触底最多追加 160 条；气泡外空白拖动到最底并松开后追加一次。沿当前筛选保留已显示内容、选区和锚点，未看消息不提前读完。手动“更多消息”仍替换为已加载范围之后一页；失败可再次向下滚动或手动重试，不跳最新、不发起网络补扫。 |
| 六项颜色 | 聊天背景、普通/重点昵称、普通/重点气泡与重点正文独立调整。HEX 只接受 #RGB 或 #RRGGBB，也可使用颜色选择器。局部合成预览不改变真实聊天；保存当前账号，取消不保存，恢复默认只修改草稿。 |
| 默认配色 | 重点昵称与正文默认为 `#860000`，重点气泡默认为纯色 `#fcd3d4`。旧五项自定义颜色保留，没有新增正文项时使用自动模式；未配置账号与恢复默认使用六项新默认。 |
| 可读性 | 普通正文及自动模式的重点正文保持至少 4.5:1 对比；显式重点正文和昵称低对比时只提示，不改写选择。链接继续保持可读性，显式正文颜色不承诺对比保证；不接受透明度或任意 CSS。 |

表情维持 409 个映射、408 份官方原图和九个已核实的旧路径，没有新增表情资源。保留已确认的引用限制：网页版详情及目标列表缺少原消息 ID 或原图地址时，显示“当前网页数据无法确认这条引用的原图，暂不能可靠打开。”，不猜测或拼接配图。

保留视频与实况照片预览自动播放、受限 HEVC 本机兼容预览、HEIF、PDF、原文件保存、分钟筛选、收藏摘要和本地回收区。开发验证不删除真实数据、不调用真实 AI 或 Notion；私人参考材料、安装备份、账号数据和诊断记录不进入分发包。

日常使用一个固定安装目录，升级前正常退出并完整备份，保留原 `data/`。软件不会自动安装。首次实际回收后的格式 2 规则不变；本地验收范围见 [测试说明](TESTING.md)，附件哈希以同批次 SHA256SUMS.txt 为准。
