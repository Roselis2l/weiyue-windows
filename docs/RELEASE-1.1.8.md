# WeiYue Windows 1.1.8

本版本修复中文输入法在消息搜索中组词被打断的问题，并保护筛选前的阅读位置和未读边界。

## 主要变化

- 组合输入期间保留输入框和草稿，后台刷新等待组合结束。
- 组合完成后延迟查询；普通 Enter 立即提交，输入法确认键不会误提交未完成文本。
- 切换账号、群聊或页面后丢弃过期查询，避免旧结果覆盖当前视图。
- 筛选阅读不覆盖普通阅读锚点，清除最后一个筛选后恢复原位置和滚动偏移。

保留官方网页登录、选群同步、成员及日期筛选、重点成员、收藏备注标签、按时段摘录、用户配置的 AI 总结和预览确认后的 Notion 导出。

## 已知边界

- 输入组合测试包含 CDP 和 DOM 模拟。Windows 原生中文输入法候选窗口仍需人工验收，不能把自动化结果等同于真实候选框实测。
- AI 和 Notion 通过模拟服务验证；用户的实际模型权限、余额、网络和 Notion 页面授权需自行配置后确认。
- 微博网页接口可能变化；同步只读取账号可见、已选群聊的记录，不保证服务端历史完整性。
- 时段摘要只处理本地已有记录；缺口提示及引用有助核对，但不能证明没有缺失消息。
- 图片按需加载，视频与文件不下载，媒体不提供完整离线备份。
- Portable 包未使用代码签名证书。运行时及第三方组件适用各自许可证，见 [第三方声明](THIRD-PARTY-NOTICES.md)。

## 文件与升级

计划发布文件为 Windows x64 portable ZIP、完整源码 ZIP 和对应 `SHA256SUMS.txt`。本说明不代表远端 Release 已经创建；以实际发布附件为准。

升级前完全退出程序并备份整个 `data/`。将新版解压到单独目录，核对校验值和版本后再按需迁移数据；保留原副本直到确认可用。迁移到其他 Windows 用户或设备时，受保护凭据可能需要重新配置。不同独立安装的数据目录不要直接合并。
