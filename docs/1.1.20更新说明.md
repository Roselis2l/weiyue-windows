# 1.1.20 候选更新说明

本候选调整聊天气泡布局并新增一项官方路径表情。实际 Windows EXE 验收结果与附件哈希以随候选提供的独立验证报告为准；候选包不会自动升级日常安装。

| 改动 | 使用方式与边界 |
| --- | --- |
| 普通消息 | 浅灰聊天区内使用随内容收缩的白色正文气泡，左上小尾角与轻阴影；头像及昵称位于框外。长文本换行，媒体和引用适应可用宽度。 |
| 重点消息 | 正文使用深色气泡、浅色文字及可读链接；框外昵称加粗并使用主题色，头像与昵称区域保持透明。取消重点恢复普通白色气泡，阅读定位与选择保留独立外层标记。 |
| 拖动与选择 | 气泡外空白区域按住左键拖动可滚动；气泡内正文可选取，气泡内边距、链接、图片和按钮不触发拖滚。松开、离窗、失焦或切换视图时停止，避免拖动后的意外点击。系统通知继续使用可展开的紧凑行。 |
| 路径表情 | 新增官方紫底“空”图标对应的 `[/ee88ab.png]`，使用官方 PNG 原字节，支持半角和全角括号，失败保留原文。现有 409 个映射、408 份官方原图，含九个已核实的旧路径；不添加猜测的 `[空]` 别名。 |

保留 1.1.19 的真实限制：若网页版详情及目标列表未提供原消息 ID 或原图地址，图片引用仍不能打开，显示“网页版未提供原图信息”；不按昵称、相似文字或相邻消息猜测配图。旧记录一次信息补全不保证取得官方未提供的信息。

视频与实况照片预览自动播放、受限 HEVC 本机兼容预览、HEIF、PDF、原文件保存、分钟筛选、收藏摘要和本地回收区继续保留。日常使用一个固定安装目录，升级前完整备份、保留原 `data/`；候选不会自动安装。首次实际回收升级账号格式 2 的规则不变，1.1.16 及更早版本不能直接读取格式 2。

实际 EXE 验收与附件哈希以独立验证报告为准。开发验证不删除真实消息、不调用真实 AI 或 Notion；私人参考图、聊天记录和诊断素材不进入分发包。
