# 微阅 Windows 1.1.15 更新说明

每份“时段摘要”右上角新增垃圾桶按钮。点击后显示应用内确认框，默认取消；确认删除当前账号、当前群的这份本地摘要，按固定 ID 定位，避免同名摘要或列表顺序变化导致误删。

删除成功后结果保存到本机，重启仍生效。取消或保存失败时保留摘要；确认期间账号或目标变化时停止并提示。该操作不删除聊天原文、收藏、阅读位置、其他账号资料或导出日志，不调用 AI 或 Notion，也不影响已经导出的 Notion 页面。

Notion 预览页核对目标、标题、正文及引用后，点击“确认导出”直接提交，去掉重复的发送确认勾选及后续弹窗。保留目标和字段校验、提交中防重复、错误提示与成功结果链接。“引用原文与本地定位”仍是独立的内容选项。

表情扩展为本次核验的官方公开目录：308 个名称、307 份独立 PNG，支持方括号及全角括号，保持原文复制、搜索、收藏、导出和摘要语义。原始目录、逐项映射及资源哈希随源码保留。当前公开目录没有官方动画 GIF；登录后专属或动态表情范围尚未取得，未知代码仍保留原文，详见 [微博表情说明](WEIBO-EMOTICONS.md)。

继续保留分钟级时间筛选、可搜索成员多选、最新已读位置、HEIC 本地显示与原件保存、PDF、视频、图片查看器和安全网页链接。相关来源、对应源码及许可证随包保留。

本轮验收应覆盖删除取消、确认、持久化失败、固定 ID 隔离、重启恢复及实际 Windows EXE，通过模拟服务检查普通摘要和多选收藏的 Notion 导出，逐项核对完整公开表情目录和资源显示，并回归阅读与媒体功能。测试使用独立合成资料；实际测试数量、完成结果和未验证范围以同次交付报告为准，这里不预填通过成绩。

真实微博登录和服务权限、付费 AI 调用及真实 Notion 写入不由合成测试证明。删除行为的验证不会删除用户真实摘要。
