# 微阅 Windows 1.1.24

设置 → 外观颜色新增“普通成员消息文字颜色”，默认黑色 `#000000`。可用颜色选择器或 `#RGB` / `#RRGGBB` 输入设置，并在合成示例中预览。

- 点击“保存颜色”后只保存到当前账号，正常重启后保留。
- 取消不保存；“恢复默认”只改变草稿，保存后普通正文恢复黑色。
- 旧配置缺少此字段时取黑色，其他配色和重点正文配置保持。普通与重点成员使用各自独立正文颜色。
- 低对比颜色会提示，但不改写选择。昵称、系统通知、链接及媒体控件继续遵循各自原有规则。
- 保留双向翻页、5 秒当前群优先刷新、收藏、摘要和媒体功能。

本轮仅本地开发与交付，不自动发布 GitHub。实际单测及 Windows EXE 验收结果、版本哈希和限制以同批验证报告为准；构建成功不代表验收通过。

便携版请固定日常目录。升级前正常退出并完整备份，更新程序文件时保留原 `data/`；各账号数据与阅读状态不应因配色更新而重置。使用方法见[中文说明](使用说明.md)，验证范围见[复核说明](TESTING.md)。
