# 微博表情来源与显示

1.1.15 使用微博官方公开字典 `https://h5.sinaimg.cn/m/emoticon/all.json` 中的完整 308 项名称映射，不使用近似 Unicode 表情。字典在 2026-10-20 匿名读取成功，HTTP 200，无 Cookie、Key 或重定向；原始 40,490 字节 SHA-256 为 `dbb40c5d913027d90d8ef09ab20943553d84baccbf0967f5c26689a107b304db`。

本次目录含七个分类，308 个确切官方图片 URL 全部返回 HTTP 200 并通过图片结构核验，全部为 PNG。`航天员` 与 `宇航员` 的两个官方 URL 返回相同字节，因此包内去重为 307 份独立原图；这不是按相似外观猜测别名。

完整原始字典保存在 `app/renderer/emoticons/catalog-source.json`，每个名称、官方 URL、本地路径、格式、尺寸和 SHA-256 保存在同目录 `catalog-manifest.json`，实际显示映射为 `app/renderer/emoticon-manifest.js`。发布流程逐项比较字典名称集合、URL、映射与本地资源哈希，并核对源码和 portable 一致。以下是沿用的三项示例：

原图字节保持不变。所有目录名称均接受 `[名称]` 与 `【名称】` 两种括号形式；全角写法是本应用的兼容输入别名，显示同一对应图像，不改写原始文字。

表情使用稳定的内联占位。资源由应用本地提供并缓存，显示时不请求微博、第三方 CDN、AI 或 Notion。缺失、损坏或加载失败时在相同位置显示原始代码，鼠标悬停可查看完整代码。表情不是用户分享的图片，不加入 AI 图片输入；搜索、复制、收藏、导出和摘要使用原始文本。URL 内的代码及未知括号文本保持原样。

这些微博表情图的版权归微博及相应权利人所有，不属于本项目或参考项目 MIT 许可授予的原创代码。这里记录来源和对应关系，不声称取得额外的表情再许可。

官方聊天页面的公开客户端使用 `/webim/emotions.json`。该接口匿名请求返回 `21301` 认证错误后已停止；获得用户新的明确授权后，使用其已有登录的 Chrome 正常导航该地址一次，页面返回 `10012` 服务异常，随后停止。此结果不能证明该 API 已接受浏览器认证，未读取或导出凭据，也未继续猜测参数或重试。

以上字典是独立、无需凭据的公开目录，不证明覆盖登录后专属、活动、付费或动态 GIF 表情。当前已核验目录中官方动画 GIF 为零，不将 PNG 称为动画，也不猜测目录外地址。

开发验收使用独立合成消息，不读取真实群聊或推进真实阅读位置。完整目录显示、长代码回退、图片延迟加载及最终 EXE 的实际测试结果，以同次交付报告为准。
