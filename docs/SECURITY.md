# 安全与隐私

## 数据保存

应用按账号隔离本地聊天记录、收藏、摘要、阅读状态和服务设置。演示与导入使用独立工作区。

Portable 默认将数据写入 `WeiYue.exe` 同目录的 `data/`；源码运行使用 `.local-data/`。聊天正文、备注、摘要和导出日志使用本地文件保存，**没有对全部业务数据做加密**。Markdown / JSON 导出也是未加密文件。请把数据放在受控的 Windows 用户目录，并自行保护备份。

微博 Cookie、AI Key 和 Notion Token 通过 Electron `safeStorage` 使用 Windows 凭据保护后保存，不写入普通设置。凭据保护不可用时拒绝保存密钥；换 Windows 用户或设备后，旧凭据可能无法解密。应用设置不回显已保存 Key。

账号隔离防止应用内交叉使用数据和会话，不替代操作系统访问控制，也不防止已经能够读取当前用户文件或控制当前进程的其他程序。

## 网络行为

| 动作 | 对外发送或读取的范围 |
| --- | --- |
| 官方登录 | 在独立窗口访问微博官方页面，由用户完成登录和验证。应用不采集密码，也不借用其他应用凭据。 |
| 群聊同步 | 使用当前登录会话读取已选、有访问权限的群聊。默认每 60 秒更新，可暂停。 |
| 显示媒体 | 通过受限代理按需读取允许来源的微博图片或分享信息；图片暂存内存。 |
| 生成本地摘录 | 不联网，仅处理当前群、所选时段的本地记录。 |
| AI 总结 | 用户确认后，将成员名称、时间和消息文本发到设置中的服务。长记录分段请求，可能计费。 |
| Notion 目标读取 | 使用用户提供的 Token 读取已授权目标页面。 |
| Notion 导出 | 用户编辑预览并确认后，将标题、正文和所选引用写入指定页面下的新子页面。 |
| 打开外链 | 仅允许符合校验的 HTTPS 网页，经确认后交给系统浏览器。 |

没有后台定时 AI 调用或 Notion 发送。AI 请求失败不会自动重试或切换模型。Notion 对无法确认是否已成功的写入停止重发，保留本地状态供核对。

## 运行边界

主界面开启沙箱和上下文隔离，关闭 Node 集成；仅通过受限 preload 接口执行已定义操作。官方登录页与本地应用界面分离，导航及新窗口受限制。聊天、备注和模型文本作为内容显示，不作为页面脚本执行。

AI 提供方地址必须使用 HTTPS；仅本机回环地址允许 HTTP。AI 请求不跟随重定向。聊天内容不拥有工具权限，AI 输出中的无效引用会提示需要核实。

异常显示会隐藏已知凭据及常见敏感字段。脱敏不代表任意用户粘贴内容都能被自动识别；对外提交问题时仍应检查文本。

## 备份、分享与反馈

完全退出应用后再备份整个数据目录。导出单份摘要或收藏适合分享内容，不等同于完整数据备份。媒体链接可能失效，本程序不保证完整离线归档。

提交 Issue 或分享截图时，只提供版本、操作步骤、预期结果和脱敏后的错误类别。不要上传自己的数据目录、登录状态、Cookie、Token、API Key、真实群聊原文或未经检查的导出文件。优先使用演示数据复现。

本项目不会绕过账号权限、登录验证、平台风控或群访问限制。未经代码签名的 portable 包可能触发系统来源提示；应核对下载来源与 SHA256，并遵循设备安全策略。
