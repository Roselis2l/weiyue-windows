# 微阅 1.1.27 · GitHub 版

- **重新登录恢复自动更新。** 会话失效后，在官方窗口登录并成功读取身份及群列表，会恢复该账号原本已开启的自动更新，保留已有群选择。手动关闭不会被重新打开，限流冷却仍遵守。
- **左右栏可独立收起。** 中栏顶部按钮分别控制两侧，阅读区随之扩大；两侧同时收起仍能展开。保留阅读位置、消息选择和收藏草稿，布局偏好重启后继续使用。左上角移除重复的“微阅”文字，窗口标题和版本标识保留。
- **PDF 预览更稳定。** 适应宽度只随有效宽度变化重新绘制，调整窗口高度和消息自动更新不触发反复重绘。保留翻页、缩放和原文件保存，关闭窗口取消待执行绘制。

GitHub 版取得官方明确的撤回通知后不显示撤回原文及附件，关联摘要和可能包含摘录的收藏备注保守隐藏。只处理官方实际返回的明确状态，不能保证实时发现或覆盖全部撤回；此前已导出的文件、Notion 页面和历史备份不会自动改写。

升级前正常退出，备份整个现有目录；更新程序时保留原 `data/`，继续使用同一日常安装目录。**首次持久保存非空撤回状态会采用账号格式 4，1.1.26 及更早版本不能直接读取。** 仅打开或投影显示不写入升级；降级须使用格式升级前备份，并另外保存当前完整目录，避免覆盖后来新增内容。既有回收/永久删除的格式及恢复边界仍适用。

本轮继续保留主题、七项颜色、双向翻页、媒体预览、收藏、时段摘要与主动确认的 AI / Notion 流程。操作及边界见[使用说明](使用说明.md)、[安全与限制](安全与限制.md)。成包 Windows EXE 验收、未验证项和附件哈希以同批验证报告与 `SHA256SUMS.txt` 为准。
