# 1.1.23 阅读翻页

- 在消息区使用 PageUp / PageDown 或 ↑ / ↓，到达顶部、底部时自动载入前页、后页；已在边界时继续按对应键也可触发。
- 鼠标滚轮、触控板和气泡外空白拖动支持顶部载入前页，保留底部载入后页。拖动松开后载入，每次连续手势或按住一个键最多一页。
- 前页插入现有消息之前，保留当前可见消息、像素位置及选区。回看不降低已读高水位，未看到的新页不会因载入被全部标为已读。
- 输入、编辑、日期、下拉、媒体及弹窗保留自身按键；其他栏不会触发消息分页。手动分页仍可用，错误可以重试，切群或筛选变化后旧结果不会混入。

分页只读取已保存在本机的消息，每页最多 160 条，不触发网络补扫。“加载到最新”和“最新已读位置”保持各自独立作用。

沿用 1.1.22 的自动更新调度：正常一轮完成后 5 秒再检查，当前阅读群优先，其他群最新页至少间隔 60 秒轮转；实际还包含网络耗时及限流退避。这不是所有群每 5 秒固定更新或官方频率保证。

请固定一个日常安装目录。升级前正常退出并完整备份程序及 `data/`，更新程序时保留原 `data/`。已有回收格式与降级限制不变。此版本不自动覆盖现有安装，也不会替用户删除消息。全量单元 1016 项、源码窗口 13 项及最终 EXE 专项 10 项通过；测试仅使用隔离合成数据，范围见 [测试说明](TESTING.md)，附件哈希以同批次 SHA256SUMS.txt 为准。
