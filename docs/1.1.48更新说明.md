# 1.1.48 长 HEVC 手动低清预览

- 原生播放器不能播放的 HEVC 视频，若符合 200 MiB、5 分钟及结构/画面/帧数限制，可点击“生成低清预览（本机）”。它不会自动启动或重新下载。
- 兼容预览最高640×360、15fps，可能耗时数分钟。原文件不变，“另存为”始终保存原件。关闭窗口或切换账号可取消；失败后不会自动重试。
- 长片转换要求至少2GiB可用内存，且不与其他视频转换排队；此门槛不是总内存用量上限。主进程5分钟硬截止、沙盒内部290秒截止，输出小于64MiB。
- 保留短片100MiB/60秒以内的原自动兼容路径和清晰度，不把所有视频降为低清。
- 预览完成后再次检查实际视频时长，防止把明显截断的结果当成完整预览。超过范围或损坏、加密的文件仍可能无法转换，可保存原件用支持HEVC的播放器查看。
- 不新增网络请求，不引入原生转码器，也不改变消息保留策略、阅读状态或AI/Notion发送范围。

本轮构建和最终EXE验收结果以独立交付报告为准。日常安装与GitHub发布不随候选构建自动改变。
