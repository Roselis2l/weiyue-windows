# 微阅 Windows 1.1.55 使用说明

- 经官方页面核实的独立动态表情链接会在消息内播放，并保留可打开、可复制的原链接。当前为精确确认列表；未确认网页、微博和视频继续显示链接，不自动抓取任意页面。加载失败可打开原链接。
- 按成员或重点成员筛选时，只包括该成员亲发的普通消息（含其回复和转发）；引用作者、系统关联通知及无原文撤回占位不计入。无成员筛选时仍显示系统通知。
- 收藏和摘要的 Markdown、收藏 JSON、Notion 引用预览中，逐条附实际发送者稳定 ID 和消息类型。系统关联成员另行标注，不冒充发送者；旧摘要无法精确补足时标为未知。正文与群/消息 ID 格式保持兼容。
- GitHub 版：撤回占位不显示原文，也不计亲发。

升级前正常退出并备份原安装，保留原 data 目录，只替换程序文件。本次无需数据格式迁移，不改变登录、清理规则或阅读状态。请从 GitHub Releases 下载同一批次的 ZIP 与 SHA256SUMS.txt，校验后再升级。
