# 微阅 Windows

**WeiYue Windows 1.1.8** 是本地优先的微博群聊阅读应用，专注三件事：读群聊、保存有价值的内容、按指定时段回顾。

| 功能 | 用法 |
| --- | --- |
| 专注阅读 | 在微博官方页面自行登录，选择有权访问的群聊同步到本机；按成员、日期、关键词筛选，标记重点成员，记住各群阅读位置。 |
| 价值收藏 | 收藏单条或多条消息，添加备注和标签，搜索收藏，导出 Markdown / JSON，回到本地原文。 |
| 时段摘要 | 选择起止时间，检查记录覆盖和缺口，生成本地摘录或主动调用自己配置的 AI；保存摘要并通过引用回查。 |
| Notion 导出 | 配置自己的 integration，选择已授权页面，编辑预览并确认后导出摘要或收藏。 |

首次运行提供虚构演示数据。没有微博、AI 或 Notion 配置，也可以使用演示、JSON 导入、阅读、收藏和本地摘录。

## 开始使用

Windows x64 portable 包包含运行时，无需安装 Node.js。取得发布附件 `WeiYue-Windows-x64.zip` 后：

1. 对照同批附件中的 `SHA256SUMS.txt` 核对文件。
2. 完整解压到当前 Windows 用户可写的目录。
3. 双击 `WeiYue-Windows-x64/WeiYue.exe`，先使用演示工作区体验。
4. 需要自己的群聊时，选择“官方登录”，在独立的微博官方窗口完成登录，再返回读取群聊并选择同步范围。

本项目未使用代码签名证书。请遵循设备安全策略，核对来源和校验值；不要关闭系统安全保护。

详细操作见 [使用说明](docs/USAGE.md)。程序的数据目录、凭据保护和对外发送边界见 [安全与隐私](docs/SECURITY.md)。

## 本地优先

聊天记录、收藏、摘要和阅读位置保存在本机，并按账号隔离。AI Key、Notion Token 和保存的微博 Cookie 使用 Windows 保护存储；聊天正文及导出文件不做整盘加密。

本地摘录不联网。AI 仅在确认后发送所选时段的成员名称、时间和文本，Notion 仅在预览确认后写入。没有定时 AI 总结或定时 Notion 发送。微博账号的已选群聊默认每 60 秒只读更新，可以暂停。

图片通过受限代理按需读取并暂存内存，不构成完整离线媒体归档；视频和文件不下载。只访问当前账号有权限的群聊，不绕过登录验证、群权限或风控。

## 开发与验证

应用使用 Electron 和 Node.js 内置模块，没有 npm 运行时依赖。核心测试需要 Node.js 22 或更新版本：

```powershell
.\scripts\test.ps1
```

构建步骤和运行时校验见 [构建说明](docs/BUILD.md)，自动化覆盖与复验方式见 [测试说明](docs/TESTING.md)。

1.1.8 修复了消息搜索中的中文输入组合被打断、Enter 误提交，以及筛选影响阅读位置的问题。核心测试 318/318 通过；输入法、阅读、AI 设置、导出和包内 UI 回归使用模拟数据及模拟服务。完整范围见 [1.1.8 发行说明](docs/RELEASE-1.1.8.md)。

当前边界：

- Windows 原生中文候选窗口仍需人工验收，CDP 与 DOM 输入事件测试不等同于系统输入法实测。
- AI 和 Notion 的自动化验证未调用真实付费服务，也未写入真实 Notion 工作区。
- 微博接入基于官方网页使用的接口，不是承诺稳定的官方 SDK；接口或风控变化可能需要重新登录或适配。
- 摘要仅覆盖已同步或导入的本地记录；AI 结果需要结合原文引用核对。
