# 微阅 Windows

**WeiYue Windows 1.1.25** 是本地优先的微博群聊阅读应用，专注读群聊、保存有价值的内容、按指定时段回顾。

**固定一个日常安装目录。** 每个 portable 目录使用独立的 `data/`。升级前正常退出并完整备份，再更新程序文件、保留原 `data/`；新解压目录不会自动带入旧资料，不要用旧数据覆盖已有新资料。

| 功能 | 用法 |
| --- | --- |
| 自动更新 | 当前阅读群优先，正常一轮完成后 5 秒再检查；其他已选群约 60 秒轮转。实际周期包含网络耗时、补扫、失败退避和限流等待，不是全部群固定 5 秒推送。 |
| 阅读与筛选 | 官方网页登录后选择群聊，按成员、关键词和北京时间分钟筛选；返回“最新已读位置”。新消息不抢走回看视口，未读按实际阅读更新。 |
| 双向翻页 | 消息区使用 PageUp / PageDown、↑ / ↓，或滚轮、框外空白拖动，到顶部载入前页、到底部载入后页。每页最多 160 条本地消息，保留当前可见位置与选区；每次连续手势或按住一个键最多一页，输入框、媒体及弹窗保留自身按键。 |
| 消息外观 | 紧凑气泡、框外拖动滚动、头像悬停操作；设置中预览和保存聊天背景、普通/重点昵称、普通/重点气泡及普通/重点正文颜色。普通正文默认黑色，颜色可独立预览、保存、取消和恢复默认。 |
| 价值收藏 | 收藏单条或多条消息，添加备注和标签，搜索、导出 Markdown / JSON，并回到本地原文。 |
| 时段摘要 | 指定时段生成本地摘录；使用自配 AI 时先核对待发送内容。摘要或收藏可编辑预览后确认导出到自己的 Notion 页面。 |
| 媒体 | 图片、PDF、视频及实况照片预览，下载受支持附件。 |
| 本地清理 | 默认移入可恢复回收区；可选直接永久删除，也可永久删除回收区所选批次。按群、北京时间分钟和保留规则预览准确数量，再确认；中栏显示实际进度，完成后刷新当前群。 |
| 大群阅读 | 复用经过文件指纹验证的本地快照，减少反复读取和解析整库的等待；保留分页、筛选与阅读状态。 |

没有账号或服务配置，也可使用演示数据、JSON 导入、收藏和本地摘录。完整操作见[中文使用说明](docs/使用说明.md)，本轮功能及边界见[更新说明](docs/1.1.25更新说明.md)。

## 开始使用

1. 在[发行页](https://github.com/Roselis2l/weiyue-windows/releases)取得同批次 `WeiYue-Windows-x64.zip` 和 `SHA256SUMS.txt`，核对校验值。
2. 完整解压后运行 `WeiYue-Windows-x64/WeiYue.exe`。Windows x64 包含运行时，无需安装 Node.js。
3. 需要自己的消息时，打开“官方登录”，自行完成微博验证并选择同步群聊。自动更新可随时暂停。

软件未使用代码签名证书；请核对来源、遵循设备安全策略。回收区是可恢复隐藏；**永久删除不可恢复**，从活动账号库移除消息内容，仅保留群 ID、消息 ID 和时间的最小标记防止同步补回，不是磁盘安全擦除。首次实际回收升为格式 2，1.1.16 及更早版本不能读取；首次非空永久删除升为格式 3，1.1.24 及更早版本不能读取。降级须使用对应功能启用前的完整备份，并另外保留当前数据；预览或取消不升级格式。

## 本地优先与边界

聊天按账号保存在本机；Cookie 和服务密钥使用 Windows 保护存储，业务数据与导出文件没有整体加密。AI 只在核对内容并确认后发送到用户配置的服务，Notion 只在编辑预览确认后写入；没有定时 AI 或 Notion 发送。媒体在本机处理，不因可以预览而自动提交给 AI。

5 秒是正常成功完成后的本地调度等待，不是微博公布或保证的接口频率。后台群、补扫与当前群共用请求保护；失败和限流会延后检查。缺少原消息 ID 或原图地址的引用仍无法打开，不猜测配图；未知表情保留原文。短 HEVC 本机兼容预览受 20 MiB、30 秒及尺寸等限制，不保证所有编码、失效链接或服务器历史都可读取。具体范围见[安全与限制](docs/安全与限制.md)。

## 源码测试与构建

需要 Node.js 22+、PowerShell 5.1+。核心测试无需 `npm install`：

```powershell
./scripts/test.ps1
```

将 Electron 44.9.0 官方 Windows x64 ZIP 与同版 `SHASUMS256.txt` 放入干净源码副本的 `vendor/` 后执行：

```powershell
./scripts/package.ps1 -ElectronVersion 44.9.0 -OutputDirectory dist-1.1.25
```

本轮本地全量单元 **1091 项**、源码窗口 **13 项**、最终 EXE 清理与阅读状态专项 **13 项**通过。删除动作使用隔离合成账号；另用本机私有隔离副本作性能测量，公开包不包含这些数据。未进行真实微博压力测试，未调用真实 AI 或写入真实 Notion。公开包只整理文档与合成示例图，程序字节保持验收版一致。范围与限制见[测试说明](docs/TESTING.md)。分发包不得包含用户数据、凭据、私有截图或备份。
