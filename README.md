# 微阅 Windows

**WeiYue Windows 1.1.27 · GitHub 版**是本地优先的微博群聊阅读应用，用于阅读群聊、收藏有价值的内容，以及按时段生成摘录或 AI 总结。

本仓库与公开下载对应 GitHub 版。实际 Windows EXE 验收结果与附件哈希以同批验证报告和 `SHA256SUMS.txt` 为准。

## 功能

本轮重新登录后的自动更新恢复、左右栏收起与 PDF 预览改进见 [1.1.27 更新说明](docs/1.1.27更新说明.md)。保留 [1.1.26 主题与附件预览](docs/1.1.26更新说明.md)、[1.1.25 本地清理与大群读取](docs/1.1.25更新说明.md)、[1.1.24 正文颜色](docs/1.1.24更新说明.md)、[1.1.23 双向翻页](docs/1.1.23更新说明.md)及 [1.1.22 自动刷新](docs/1.1.22更新说明.md)。源码测试与成包 EXE 验收分别记录，不以编译成功代替窗口验证。

| 功能 | 操作方法 |
| --- | --- |
| 自动更新 | 正常批次完成后 5 秒再检查，当前阅读群优先；其他群的最新页至少间隔 60 秒轮转。补扫短批次与实时消息共用单飞和 1 秒分页间距，失败及限流仍退避。5 秒是本地正常周期下限，不是所有群的保证刷新时间。 |
| 重新登录 | 会话失效后，在官方窗口完成登录并成功读取群列表，会恢复该账号原来已开启的自动更新，同时保留原有群选择。手动关闭的自动更新不会因登录被打开，限流冷却仍保留。 |
| 紧凑阅读布局 | 中间栏省去重复标题；底部依次放置“加载到最新”、分页、“最新已读位置”。头像左侧的选择框和下方的收藏、重点图标默认隐藏；鼠标进入头像及按钮的连续操作区，或键盘焦点进入时显示，整条消息悬停不会触发。 |
| 收起两侧栏 | 中栏顶部的“收起左栏”“收起右栏”独立控制两侧，中栏随之扩大；两侧都收起时仍保留展开入口。布局偏好保存在本机，切群和重启后继续使用，不改阅读进度。左上角已移除重复的“微阅”文字。 |
| 重点成员 | 昵称在框外加粗；默认重点昵称和正文为深红色 `#860000`，气泡为纯色浅粉 `#fcd3d4`，头像与昵称区域透明。取消重点恢复普通气泡，阅读定位和选择状态保留独立外层标记。 |
| 聊天气泡 | 紧凑布局保留原字号和媒体可用尺寸；默认普通消息为白色气泡配黑色正文、重点消息为浅粉气泡配深红文字，聊天区浅灰。气泡随内容收缩，头像与昵称在框外。系统通知使用透明背景的小字紧凑显示，不使用消息框、边框、阴影或尾角；长通知仍可展开，文字根据深浅聊天背景保持清晰。 |
| 界面主题 | 设置 → 编辑主题与颜色，可选择 Cool Grey、Viridian、Pink、Violet；先看合成预览，保存到当前账号。主题与已有七项消息颜色分别设置和恢复默认，取消不保存。 |
| 颜色设置 | 聊天背景、普通/重点昵称、普通/重点气泡及普通/重点正文七项可分别调整，支持 HEX、颜色选择器和局部合成预览。保存当前账号，取消不保存，恢复默认只改草稿。普通正文默认黑色 `#000000`；重点正文保留独立颜色及可选自动对比。显式颜色低对比只提示，不改写用户选择；旧配置缺少普通正文字段时取黑色，其他配色保留。 |
| 拖动与通知 | 在消息周边空白处按住左键可拖动滚动；气泡内正文仍可选择复制，内边距与控件不触发拖滚。确证的系统通知以无框小字收为一行，长通知可展开；不依据群名或昵称折叠普通消息。 |
| 双向翻页 | 消息区使用 PageUp / PageDown 或 ↑ / ↓ 滚到顶部、底部时，自动载入前页、后页；已在边界时继续按对应键也可触发。滚轮或气泡外空白拖动也支持上下边界，每次连续手势或按住一个键最多载入一页。每页最多 160 条本地消息，沿用筛选并保留当前内容、选区和阅读位置；输入框、媒体与弹窗保留自己的按键。手动分页仍保留，不跳最新或发起网络补扫。 |
| 筛选与定位 | 按关键词、多个成员和北京时间起止分钟筛选。结束时间包含所选完整一分钟。“最新已读位置”返回已读高水位，“加载到最新”是另一个明确读到末尾的操作。 |
| 引用内容 | 有真实原帖结构的引用微博、关联微博及配图可以打开。旧记录可进行一次信息补全；网页版未返回目标 ID 或原图地址的图片引用仍不能打开，显示“网页版未提供原图信息”，不猜测配图。 |
| 图片、实况照片与附件 | 保留图片缩放、HEIC 本地显示、PDF 预览和视频播放；受支持聊天图片按实际格式显示及保存，兼容部分错误的服务端格式声明；实况照片的静态图片与关联视频分别提供入口；视频预览打开后自动播放，受限短 HEVC 在原生播放失败时自动准备一次本机兼容预览并播放，列表不自动播放。ZIP、RAR、7z 可经校验下载到自选位置，不解压或运行。 |
| 文档附件 | XLSX 提供有界只读表格预览，CSV 提供有界表格预览，Markdown 显示安全原文；不执行公式、宏、HTML 或远程内容。可另存已通过读取校验的原文件；格式、大小和编码边界见中文说明。 |
| 分享语音 | 有官方附件源时支持受检音频预览，AMR 在本机受限转换后播放。打开后播放，关闭或切换停止旧媒体，保存仍使用原始文件；文字占位或缺失源不能还原。 |
| 微博表情 | 保留 413 个映射、412 份去重官方原图，来源见表情说明。支持半角 `[]` 与全角 `【】`，未知代码保留原文。 |
| 本地数据管理 | 设置 → “管理本地消息与回收区”，按群和北京时间分钟筛选，先预览精确范围、保留规则与数量。默认移入可恢复回收区，也可选择不可恢复的永久删除；回收区支持所选批次的恢复或永久删除。中栏显示实际处理阶段，完成后刷新仍在阅读的受影响群。 |
| 收藏、摘要与导出 | 单条或多条收藏、备注与标签、原文回查、本地摘录、主动确认的 AI 总结和 Notion 编辑预览继续保留。 |

首次启动可直接使用合成演示数据或 JSON 导入，无需配置微博、AI、Notion。实际登录只在微博官方窗口完成，应用不发送群消息。

## 启动与升级

Windows x64 portable 包包含运行时，不需要安装 Node.js：核对 `SHA256SUMS.txt`，完整解压，然后运行 `WeiYue-Windows-x64/WeiYue.exe`。

**固定一个日常安装目录。** 每个 portable 目录使用自己的 `data/`；解压到新目录不会带入旧数据。升级前正常退出并备份整个现有目录，再更新程序文件，保留原来的 `data/`。不要同时从多个副本日常使用，也不要用旧数据覆盖已经产生新资料的目录。软件不会自动替换其他目录中的安装。

软件未使用代码签名证书。请核对来源和校验值，遵循设备策略，不要关闭系统安全保护。

详细操作见[中文使用说明](docs/使用说明.md)、[本轮说明](docs/1.1.27更新说明.md)和[安全与限制](docs/安全与限制.md)。

## 数据与联网范围

聊天、收藏、摘要、回收区及阅读位置按账号保存在本机。业务数据和导出文件没有整体加密；Cookie、AI Key、Notion Token 使用 Windows 保护存储。请保护整个数据目录和备份。

回收区属于**可恢复的隐藏**，仍保留原始记录，不释放相应记录占用的空间。永久删除会从当前账号的活动数据中移除选中消息正文、成员与媒体信息，不能在回收区恢复；仍保留群 ID、消息 ID 和发送时间组成的最小删除标记，防止同步、补扫或导入立即补回。收藏、摘要引用、导出关联、未读及阅读定位消息会保留；来源不完整的历史记录会保守保护，并在预览中说明。

**首次实际回收将账号格式升为 2；首次成功且非空的永久删除升为 3；首次持久保存非空撤回状态升为 4。** 仅打开或投影显示不写入升级，清理的筛选、预览和取消也不升级。恢复回收批次不会降版本。1.1.16 及更早版本拒绝格式 2，1.1.24 及更早版本拒绝格式 3，1.1.26 及更早版本不能读取格式 4。升级前请保留完整备份；降级需要相应格式升级前的备份，并另外保留当前完整数据，避免丢失后来新增内容。

GitHub 版收到官方明确的群消息撤回通知后显示撤回提示，不显示撤回原文，也会隐藏关联摘要或可能包含摘录的收藏备注。只处理官方实际返回的明确撤回状态，不能保证捕获全部或实时撤回，不把一次查询中缺少消息当作撤回。已经另存或导出到外部服务的内容不会自动改写；显示隐藏不等于清除历史备份。

永久删除不是磁盘安全擦除，也不会清理先前备份、已导出文件、浏览器缓存或服务器记录；这些位置可能仍有历史副本。程序不会为释放空间而删除备份或擅自修改已导出的 Notion 页面。

本地摘录不联网。AI 只在核对发送范围并确认后调用用户配置的服务；Notion 只在编辑预览确认后写入。开发验收不得调用真实付费 AI 或写入真实 Notion。微博自动更新仍是只读同步，可暂停。

媒体经允许来源、体积及实际格式校验后按需读取，不等同于完整离线媒体归档。表情与头像不作为 AI 图片输入。实况视频、PDF、压缩文件也不会因可本地打开而自动发送给 AI。

## 源码与构建

需要 Node.js 22+、PowerShell 5.1+。核心测试：

```powershell
./scripts/test.ps1
```

将已核验的 Electron 44.9.0 官方 Windows x64 ZIP 与同版 `SHASUMS256.txt` 放入干净源码副本的 `vendor/`，执行：

```powershell
./scripts/package.ps1 -ElectronVersion 44.9.0 -OutputDirectory dist-1.1.27
```

构建不执行启动时依赖安装；图片解码库和 PDF.js 固定版本随包提供。输出目录不得覆盖已有构建。打包成功不等于实际 EXE 验收通过，具体测试和未验证项见同批交付报告及[复验说明](docs/TESTING.md)。

源码及便携包不得包含 `data/`、凭据、浏览器状态、诊断输出、真实截图或备份。

## 支持边界与许可

- 普通图片单张上限 20 MiB，HEIC 解码另有像素、时间及显示图限制；PDF 上限 50 MiB，视频和压缩文件上限 200 MiB。XLSX 读取上限 20 MiB，Markdown/CSV 为 5 MiB，预览还限制展开量、行列和文本长度；超读取上限不下载。打开视频预览后，原生播放失败的短 HEVC 自动进行一次本机兼容转换：仅限 20 MiB、30 秒以内且尺寸等校验通过的文件，显示“正在本机准备兼容预览…”。成功后自动播放，保留暂停、音量和进度控制，原文件不变；关闭窗口可取消。失败不自动循环，可主动重试或保存已通过文件校验的原文件。损坏、失效、加密或无权限文件仍可能无法取得。
- 仅有文字占位或缺失关联信息时，无法可靠还原原帖、原图或实况视频。已核查的缺失目标信息的图片引用仍不能打开；一次补全也不能获得网页版未提供的原图。
- 本次表情资源均为已确认的静态 PNG；未核实的专属和动态目录继续回退原文，不能据此声称全微博表情覆盖。来源和数量见[微博表情说明](docs/WEIBO-EMOTICONS.md)。
- 自动化输入组合测试不等于 Windows 原生输入法候选窗口的人工验收；真实 AI、Notion 和每种服务端媒体响应不在本地模拟测试的保证范围内。
